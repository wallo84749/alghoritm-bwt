# BWT Project – Burrows-Wheeler Transform

**Author:** Walid Mabrouki  
**Class:** 5C IT  
**Start date:** 28/10/2026

This project was developed during a classroom lesson about the **Burrows-Wheeler Transform (BWT)**.

The goal is to create a **Python** program that transforms a text string using the BWT algorithm.

The project uses a client-server architecture with **TCP** sockets to send text to the server and receive the transformed result.

The project also includes **Quick Sort**, a sorting algorithm used to sort the rotations of the input string.
